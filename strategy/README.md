# 🌐 NEXUS — Network of EXperts, Unified in Strategy

NEXUS turns this library's specialists into a **coordinated pipeline** instead of agents you activate one at a time and hope work together. It defines who does what, when they hand off, and how quality is verified at each step — scaled for a solo founder or a small team, not a 200-person agency.

> Built for the current **8-division, 106-agent** roster. The conductor is the **Agent & Workflow Orchestrator**; the final quality gate is the **QA Reality Checker** (defaults to "NEEDS WORK" until evidence proves otherwise).

## The 8 divisions

| Division | What it covers |
|---|---|
| **Engineering & AI** | Build, QA, security, AI/agents/automation |
| **Product & Design** | What to build; UX, UI, brand |
| **Marketing & Content** | Organic content, social, SEO, PR |
| **Growth & Performance** | Paid media, CRO, email, acquisition |
| **Sales & Customer** | Sell, support, retain |
| **Finance & Law** | Money, tax, legal, pricing |
| **Operations & People** | Projects, ops, HR, admin, BI |
| **Strategy & Advisory** | Deep consultants & cross-domain strategy |

## Three modes

| Mode | Scope | Agents | Typical time |
|---|---|---|---|
| **NEXUS-Full** | A complete product, end to end | most divisions | weeks |
| **NEXUS-Sprint** | One feature or an MVP | a focused subset | days–weeks |
| **NEXUS-Micro** | A single task (bug, campaign, audit) | a handful | hours–days |

## The pipeline

```
Phase 0      Phase 1       Phase 2      Phase 3        Phase 4     Phase 5     Phase 6
DISCOVER ──▶ STRATEGIZE ─▶ SCAFFOLD ──▶ BUILD ───────▶ HARDEN ──▶ LAUNCH ──▶ OPERATE
intelligence  architecture  foundation   Dev↔QA loop    quality     go-to-     sustained
                                                          gate       market     ops
  ◆ Quality gate between every phase   ◆ Parallel tracks within a phase   ◆ Max 3 retries per task
```

## Activate it

Point the **Agent & Workflow Orchestrator** at your goal and let it drive the pipeline:

```
Activate the Agent & Workflow Orchestrator in NEXUS-Sprint mode.
Goal: [what you're building]
Run: Strategize → Build (Dev↔QA loops) → Harden → Launch.
Quality gate between phases; QA Reality Checker approval required before launch;
max 3 retries per task before escalation.
```
